# Использование ИИ в проекте FX Portal

В процессе разработки команда использовала нейросеть **Claude (Anthropic)** для автоматизации рутинных задач и ускорения работы.

## Задачи, в которых применялся Claude:

- **Написание и проверка кода** — помощь в реализации модулей авторизации, API-запросов и экспорта отчётов
- **Анализ архитектурных решений** — обсуждение структуры проекта, выбор подходов к организации модулей
- **Написание тестов** — помощь в составлении тест-кейсов для `tests.py`
- **Оформление документации** — помощь в написании README и технической документации
- **Отладка ошибок** — анализ traceback'ов и поиск причин багов

## Вывод

Использование Claude позволило сократить время на рутинные задачи и сосредоточиться на архитектуре и логике проекта.
