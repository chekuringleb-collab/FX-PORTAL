## 🌍 О проекте

**FX Portal** — веб-приложение для мониторинга курсов валют в реальном времени.  
Получает актуальные данные с публичного API, отображает графики истории, позволяет конвертировать валюты, сравнивать несколько валют одновременно, загружать свои файлы с курсами и экспортировать отчёты.

> Учебный проект команды из 3 студентов по дисциплине «Проектирование программных продуктов»

## 👤 Создание администратора

Для регистрации аккаунта с правами администратора используй секретную страницу:

```
http://localhost:5000/admin-register/fx-admin-2026
```

> ⚠️ Смени секретный ключ в `.env` перед деплоем:
> ```
> ADMIN_SECRET=твой_секретный_ключ
> ```

Обычная регистрация `/register` создаёт только пользователей с ролью `user`.

## 🧮 Калькулятор

Страница `/calculator` — полноценный калькулятор с историей вычислений.

**Поддержка процентов:**

| Выражение | Результат |
|---|---|
| `100 - 20%` | `80` (20% от 100 = 20) |
| `100 + 20%` | `120` (20% от 100 = 20) |
| `100 * 20%` | `20` (100 × 0.20) |
| `100 / 20%` | `500` (100 ÷ 0.20) |
| `20%` | `0.2` |

История сохраняется в браузере, можно кликнуть на запись чтобы использовать результат.

---

## 📂 Загрузка файлов

Страница `/upload` принимает CSV и Excel файлы с курсами валют.

**Формат файла** (такой же как при экспорте с сайта):
```
Код;Валюта;Флаг;Курс к USD;Дата
EUR;Евро;🇪🇺;0.9234;2026-05-18
GBP;Британский фунт;🇬🇧;1.2651;2026-05-18
```

После загрузки автоматически строятся таблица и графики по каждой валюте.

## 🔐 Безопасность

- Пароли хешируются через `pbkdf2:sha256` с 600 000 итерациями
- `SECRET_KEY` читается из переменной окружения
- Защита от открытых редиректов
- `SESSION_COOKIE_HTTPONLY` и `SAMESITE=Lax`
- Раздельные роли: `admin` и `user`
- Скрытая страница регистрации администратора
- Блокировка пользователей без удаления аккаунта
- Логирование всех действий в системе
- Кеширование снижает нагрузку на внешний API
